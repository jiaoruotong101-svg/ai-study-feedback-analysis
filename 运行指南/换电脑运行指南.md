# 换电脑运行与结果复现

## 1 安装什么

建议使用Windows 10或11的64位电脑，普通CPU即可，不需要显卡、CUDA、API密钥或付费AI服务。

安装64位Python 3.13，并安装Python Launcher（安装器里的py启动器）。原实验记录为Python 3.13.14。运行时优先使用相同版本；其他3.13补丁版可先运行本包的结果核验，以实际验证为准。Python官网：https://www.python.org/downloads/ 。不要将来源不明的软件包或模型替换进本包。

查看报告和人工表格时可使用Word/Excel或WPS；这些办公软件不参与模型评测。无需安装Codex、Node.js或图像生成软件来复现模型结果。

依赖已根据原实验运行环境的实际安装版本整理到requirements.txt，包括numpy、pandas、pyarrow、scikit-learn、joblib、scipy和threadpoolctl。首次安装需要联网；不要在版本找不到时直接改成最新版，否则可能无法加载旧模型。保留报错，再检查Python版本、网络或软件源。

## 2 解压并先运行哪个脚本

完整解压ZIP，例如放到D:\StudyCourse。不需要复制到原电脑的D:\projects\Study。不要直接在压缩包中运行，也不要改变outputs内部目录层级。

最简单的方法：双击“运行指南\一键复现.cmd”。它会：

1. 在解压根目录创建.venv虚拟环境。
2. 安装已列明版本的依赖。
3. 运行“运行指南\复现评测.py”。
4. 将必要模型与输入复制到一个新的时间戳目录，调用原evaluate_frozen.py，并自动比较全部评测指标。

这是换电脑后首先应该执行的流程。不需要先下载数据、重新抽样、重新标注或重新训练。

如果双击失败，可在解压根目录打开PowerShell，逐行执行：

```powershell
py -3.13 --version
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r .\运行指南\requirements.txt
.\.venv\Scripts\python.exe .\运行指南\复现评测.py
```

上述命令不要求激活虚拟环境，因此无需修改PowerShell执行策略。路径有空格时，使用引号包围路径。若使用macOS/Linux，安装Python 3.13后以python3.13创建虚拟环境，改用.venv/bin/python执行同一Python脚本即可；Windows启动文件仅用于Windows。

## 4 若老师要求重新训练

先复制整个解压目录，命名为“重新训练实验”。在副本根目录运行：

```powershell
.\.venv\Scripts\python.exe .\outputs\ai-labelled-20261026\train_baseline.py
```

如副本没有可用虚拟环境，先按第2节建立环境。训练脚本使用已保存AI标签中的1,721条训练评论和347条开发评论；会覆盖副本中feedback-baseline-20261026里的model.joblib、开发预测、指标及冻结清单。训练不需要使用180条人工评测标签，也不需要重新调用AI。

训练后，副本的development_metrics.json应接近保存结果：开发准确率86.46%，具体反馈F1约84.49%。不同依赖或数值环境可能影响浮点值及模型文件哈希；新模型不是历史冻结模型，不能要求文件字节完全一样。要评价新训练模型，可在副本继续运行“运行指南\复现评测.py”，其一致性检查会明确提示是否与历史指标相同。不要为了通过检查而修改人工标签。

Excel生成和回填使用@oai/artifact-tool以及原Codex环境。本包保留历史脚本供追溯，但不承诺普通Python环境即可重建Excel；最终Excel和JSON决策记录均可直接使用。生图改图相关输出不在本包内，最终报告已保留。

## 6 常见报错

- “py不是内部或外部命令”：检查是否安装Python Launcher，或用Python安装目录下python.exe的完整路径替代py -3.13。
- ModuleNotFoundError：用.venv内的python执行pip安装及评测，不要混用电脑上其他Python。
- 安装依赖时没有匹配版本：先核对64位Python 3.13及网络/软件源，不盲目升级或更改requirements。
- 模型哈希断言失败：模型或配置被改动。重新解压原包，先运行复现评测，不先运行训练。
- 找不到human_decisions等文件：保持完整目录结构，勿只复制单个脚本。
- 指标不一致：保存完整报错和新metrics.json，检查版本及输入文件是否变化。不要把不同结果当作复现通过。
