# AI 学习助手用户反馈分析

给 AI 学习助手做一次用户体验体检：从公开评论中识别具体问题与改进需求，并检查自动分类与人工判断的一致程度。大数据课程设计项目。

## 项目内容

- 原始 GenAI-EdSent 数据：480,831 条评论，22 个教育应用。
- 清洗后的六应用研究范围：82,004 条评论，涉及 Gauth、Question.AI、Answer.AI、Nerd AI、StudyX、Homework AI。
- 方法：TF-IDF 单词及双词特征 + 逻辑回归，先识别是否有具体反馈，再独立判断四个问题类别，可同时命中多个类别。
- 训练 1,721 条、开发 347 条，使用 AI 辅助标签。训练脚本不会重新调用 AI。
- 模型在人工测试前冻结；180 条人工判定中，178 条可计分，2 条不确定。

## 已保存的评测结果

| 指标 | 结果 |
| --- | ---: |
| 有无具体反馈准确率 | 87.64% |
| 具体反馈精确率 | 84.31% |
| 具体反馈召回率 | 93.48% |
| 具体反馈 F1 | 88.66% |
| 四类微平均 F1 | 71.35% |

四类为回答与任务完成、收费与权益、运行体验、界面与广告。入门求助因样本不足未训练。

人工判定由用户最终决定，AI 提供翻译和候选选项，判定时未展示冻结模型预测；这不是完全无提示的独立人工标注。上述分数不代表全部评论的准确率，不是学习助手解题正确率，也不是产品排名。旧资料中的 91.61% 属于早期评分预测实验。

## 复现

在本仓库根目录按运行指南安装匹配的 Python 与依赖，然后运行：

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r .\运行指南\requirements.txt
.\.venv\Scripts\python.exe .\运行指南\复现评测.py
```

也可以在 Windows 双击 `运行指南/一键复现.cmd`。评测在新的 `复现运行` 目录执行，逐项比较历史指标，不覆盖原始结果。依赖版本沿用原实验记录；本次 GitHub 归档未重新安装环境或运行训练评测。部分早期过程脚本含旧机器绝对路径，使用前须调整，详见运行指南。
